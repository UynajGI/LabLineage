# 版本范围：MVP、Beta 与 Release Candidate

## 1. MVP / Alpha

必须证明核心价值，不要求覆盖所有数据类型：

- 一个本地目录 + 一个 GitHub 仓库；
- 两次无 Git 快照；
- Python、Notebook、YAML、日志基础解析；
- 离线 Bundle；
- 一张关键图的证据链；
- GitHub commit 冲突；
- duplicate/orphan/failed/stale；
- R0–R3；
- ADK 本地 Agent；
- 简单 Web 或 CLI 输出。

## 2. 平台端到端 Alpha

- Runtime 部署；
- Registry 登记；
- Gateway allow/deny；
- Drive 报告；
- Sheet 台账；
- Gmail 草稿；
- Agent 证据引用和人工确认。

## 3. Beta

- 安全威胁模型和测试；
- Agent 轨迹评测；
- 租户/项目隔离；
- 可观测性和成本；
- CI/CD、备份、回滚；
- 真实规模性能测试；
- 用户可用性测试。

## 4. Release Candidate

- 三类试点；
- 匿名案例和量化影响；
- 完整文档；
- 在线/离线演示；
- 比赛提交物；
- 版本冻结和可恢复环境。

## 5. 后续范围

- DVC、MLflow、W&B、Snakemake、Nextflow；
- GitHub Enterprise 与 GitLab；
- 真实受控复现沙箱；
- 更多语言和科学文件格式；
- 校级多租户和机构政策模板；
- 语义技能 Registry；
- 仅在有清晰 evaluator 时评估 AlphaEvolve 子模块。
