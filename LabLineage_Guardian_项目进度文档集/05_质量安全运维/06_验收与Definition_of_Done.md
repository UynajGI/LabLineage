# 验收标准与 Definition of Done

## 1. 单任务 DoD

- 交付物存在并被 reviewer 查看；
- 验收标准逐条通过；
- 相关代码有单元或契约测试；
- 无未记录的 P0/P1 缺陷；
- 文档、配置和示例同步更新；
- 日志不泄漏受限信息；
- 依赖任务和后续任务状态更新。

## 2. 功能 DoD

- 从用户入口到持久化/报告的路径可运行；
- 正常、空数据、权限不足、外部故障和重复调用均有行为；
- 接口遵循 Schema 和幂等约定；
- Agent 判断有证据引用；
- 推断与事实可区分；
- 写操作有预览与确认。

## 3. 平台集成 DoD

### ADK

- 使用正式 ADK Agent；
- 工具 Schema 可测试；
- 会话和项目上下文隔离；
- Agent eval 校验轨迹。

### Runtime

- 正式部署、调用、日志、更新和回滚均验证；
- 服务身份与权限最小化。

### Registry

- Agent、MCP 和 Endpoint 元数据完整；
- 版本、owner、环境、认证和生命周期可查。

### Gateway

- Agent 流量经 Gateway；
- allow 成功、deny 被拒绝；
- 调用主体、策略和目标可审计。

## 4. 发布 DoD

- E2E 回归通过；
- P0/P1 缺陷为 0；
- 安全评审通过；
- 数据库迁移与回滚验证；
- 备份和恢复演练通过；
- Release notes、部署、用户和故障文档完成；
- 演示环境和版本冻结。
