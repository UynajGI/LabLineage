# 最终验收清单

## 产品

- [ ] 三条核心用户旅程均可独立完成
- [ ] 关键图谱系展示事实、推断、冲突和缺失
- [ ] 无 Git 两次快照可展示更新记录
- [ ] 结果筛选不自动删除且保留科研探索语义
- [ ] 交接报告能指导接手者下一步

## 边缘与数据

- [ ] 原始数据默认不出域
- [ ] Bundle 签名、校验和、幂等导入通过
- [ ] 路径 Token 和敏感参数策略通过测试
- [ ] 大文件与中断扫描行为可接受
- [ ] Schema、Migration 和兼容策略文档齐全

## Gemini Enterprise Agent Platform

- [ ] ADK Agent 使用正式工具契约
- [ ] Agent 部署在 Runtime
- [ ] Agent/MCP/Endpoint 登记在 Registry
- [ ] Runtime 或 Agent 流量经 Gateway
- [ ] allow 与 deny 场景有演示和日志
- [ ] Agent 工具轨迹和 evidence 可审计

## Workspace

- [ ] Sheet 更新幂等
- [ ] Drive 报告有版本和审计 ID
- [ ] Gmail 只创建草稿
- [ ] 写操作均有人工确认

## 质量与安全

- [ ] P0/P1 缺陷为 0
- [ ] Prompt injection 红队通过
- [ ] 越权和跨项目测试通过
- [ ] 日志不含密钥和受限原文
- [ ] 备份、恢复、回滚和演示降级通过

## 试点与比赛

- [ ] 三类项目试点完成
- [ ] 指标区分实测与模拟
- [ ] 匿名案例无敏感内容
- [ ] 项目书逐项回应四个评分维度
- [ ] 视频、仓库、文档和演示链接可访问
- [ ] 至少两名成员能够独立演示
