# 版本发布计划

## 1. 版本序列

| 版本 | 目标 | 进入条件 | 退出条件 |
|---|---|---|---|
| 0.1 Collector Alpha | 扫描、哈希、快照、Bundle | Schema v1 | M2 通过 |
| 0.2 Lineage Alpha | GitHub、谱系、R 等级、Finding | 0.1 稳定 | M3 通过 |
| 0.3 Platform Alpha | ADK/Runtime/Registry/Gateway/Workspace | 核心 API 稳定 | M4 通过 |
| 0.5 Beta | 安全、评测、UI、可观测、发布工程 | 平台 Alpha | M5 通过 |
| 0.8 Pilot | 三类项目试点 | Beta Gate | M6 通过 |
| 1.0 RC | 比赛与公开交付 | 试点问题关闭 | M7 通过 |

## 2. 版本兼容

分别版本化：

- Collector；
- Manifest Schema；
- Ingestion API；
- 数据库 Migration；
- ADK Agent；
- Prompt/Policy；
- MCP Tool Schema；
- Gateway Policy；
- 报告模板。

## 3. 发布分支

```text
main            稳定开发基线
release/x.y     发布候选修复
feature/*       功能开发
hotfix/*        已发布严重修复
```

## 4. 发布检查

- Changelog；
- SBOM 与依赖扫描；
- Migration 演练；
- Agent eval；
- Gateway deny 测试；
- Workspace 幂等测试；
- 离线 Bundle 回归；
- Demo smoke test；
- 回滚点和负责人。
