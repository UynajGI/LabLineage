# 核心术语表

| 术语 | 含义 | 不代表什么 |
|---|---|---|
| Project | 一个独立授权和审计边界内的科研项目 | 不是文件系统目录本身 |
| Source | 文件系统、GitHub、Google Drive 或离线 Bundle 等证据来源 | 不自动获得写权限 |
| Snapshot | 某一时刻目录中资产、哈希和元数据的不可变观察 | 不是目录备份 |
| Manifest | Collector 生成的结构化采集结果 | 不包含原始文件内容或绝对路径 |
| Bundle | Manifest 及其签名封装；可导出为离线归档 | 签名只证明来源和完整性，不证明科研结论正确 |
| Node | 图中的数据、代码、参数、环境、运行、图表或结论 | 不一定已被人工确认 |
| Edge | 两个节点之间的“使用、生成、引用”等关系 | 候选 Edge 不等于事实 |
| Evidence | 支持节点或关系的哈希、签名记录、平台事件或人工审核 | 不是模型的自由文本解释 |
| Candidate | 基于解析或推断得到、仍需核实的对象或关系 | 不是已确认事实 |
| Confirmed | 平台证据或人工审核支持的状态 | 不保证完整性或可复现性 |
| Finding | 确定性审计规则发现的风险或证据缺口 | 不会自动删除科研结果 |
| Status Proposal | 对资产状态的待审变更建议 | 提交后不会立即覆盖原状态 |
| Path Token | 用项目盐对相对路径生成的不可逆标识 | 不是可还原的绝对路径 |
| Idempotency-Key | 保证重试不会重复执行写操作的请求标识 | 同一个键不能安全地用于不同内容 |
| Reservation | 在写入对象前持久登记的恢复记录 | 不代表对象已经成功提交 |
| Handoff Preview | 交接报告、台账和邮件草稿的预览 | 不会自动发送邮件 |
| R0 | 没有足够的可复现证据 | 不等于结果一定错误 |
| R1–R3 | 从部分证据到完整静态谱系的逐级支持 | 不等于真实重跑已经成功 |
| R4 | 受控重跑成功且输出哈希与预期匹配 | 不能由模型推断或人工口头声明产生 |
| Guardian Agent | 只读解释谱系和发现的模型辅助功能 | 不能替代确定性审计或直接执行写操作 |

## 判断信息可信度的顺序

看到一个关系或结论时，依次检查：

1. 它是事实、候选、冲突还是缺失证据？
2. 引用了哪些 evidence ID？
3. Evidence 来自哈希、签名平台记录还是人工审核？
4. 证据是否属于当前项目和当前版本？
5. 如果声称 R4，是否存在成功受控重跑和输出哈希匹配？

术语仍不清楚时，从[10 分钟体验](quickstart.md)中的 `fig3.png` 示例观察一次完整链路。
