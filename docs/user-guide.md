# LabLineage Guardian 用户指南

界面默认中文，右上角 **EN/中文** 按钮可切换语言（选择保存在浏览器本地）。

## 1. 登录与角色

开发环境使用本地身份；生产环境必须使用 OIDC PKCE 登录。页面和 API 都按项目授权：

- `viewer`：查看项目、谱系、快照、审计与交接报告。
- `editor`：登记来源、导入 Bundle、执行扫描、提交状态提案。
- `auditor`：确认或拒绝推断边，处理审计发现。
- `admin`：机构初始化、安全摘要和运维配置。

任何写操作都带 `Idempotency-Key`。重复提交相同请求会安全重放；相同键配不同内容会返回 `409`。

## 2. 建立项目证据

1. 在“接入清单”确认机构、项目和负责人。
2. 登记 `filesystem`、`github`、`google_drive` 或 `offline_bundle` 来源。
3. 对科研服务器使用 Edge Collector；不要把原始路径、密钥或 `.lablineage/` 上传到 Git。
4. 在导入任务页观察 `queued → processing → completed/failed`。失败任务只有在修正 Manifest 并明确确认后才能重试。
5. 没有 Collector 或 Git 时，可在“上传中心”直接拖入项目 `.zip`：服务端安全解压（路径穿越条目会被跳过并提示）后扫描并指纹化，生成与目录扫描同构的快照与差异，不落库原始内容。

本地 Git 仓库可通过通用仓库同步接口采集。管理员必须先设置 `LABLINEAGE_LOCAL_GIT_ROOTS`；服务只读取允许目录，并仅保存文件路径哈希、Git 对象 ID、分支、标签和提交证据。

## 3. 查看和确认谱系

- 实线事实来自精确哈希、签名 Manifest 或已确认的平台证据。
- 候选关系、移动候选和历史推断必须显示为“推断”，不能冒充事实。
- 只有审计员能够确认或拒绝候选边；每次决定都保留评论、操作者和版本历史。
- “影响范围”用于查看某个数据或代码版本变更后可能失效的下游结果。

## 4. 无 Git 快照

首次扫描建立基线；第二次及以后扫描产生新增、修改、删除、二进制摘要和移动/复制候选。文本 diff 默认关闭，只有勾选授权并提交 `ALLOW_TEXT_DIFF` 才会读取已知文本类型，而且仍受脱敏、行数和字节数上限约束。冷归档快照会透明解压并校验 SHA-256。

## 5. 可复现审计

审计结果是确定性规则输出，不由模型决定。修复参数、环境、代码版本或输出证据后重新执行审计；已解决问题再次出现时会保留旧解决记录并重新打开。系统不会自动删除科研探索结果，状态变更必须先形成提案再人工确认。

## 6. Guardian Agent

Agent 只读调用受 Schema 限制的工具，并区分事实、推断、冲突和缺失证据。任何写入或外部 Workspace 操作必须先显示预览并由用户明确确认。模型不可用时，图谱、快照、审计和本地交接仍可正常使用。

页面顶部可以切换持久会话、创建新会话或清除当前上下文。会话按项目、登录
身份和 `conversationId` 隔离；切换会话会继续该会话的 ADK 状态，清除操作
会删除旧事件并创建空白会话。每次回答下方的“执行轨迹”展示根路由、专业
Agent、工具调用与结果、证据 ID、R 等级和耗时，便于比赛演示和问题定位。

## 7. 交接

交接使用**交接单（HandoffOrder）**模型：离任/接收/审核人与截止时间属于一张可重复、可审批、可追踪的交接单，不再放在全局系统设置里。流程：

1. **新建交接单**：填写离任/接收/审核人（认证标识 + 邮箱快照）、截止时间、时区与任务清单，生成单号（`HO-YYYYMM-NNN`）。
2. **提交审核**：草稿 → 已提交；只有指定审核人（认证 subject）能批准或要求修改。
3. **接收确认**：已批准后由接收成员确认。
4. **完成**：确定性判定——已批准 + 全部必需任务 done。
5. **预览与导出**：选中具体交接单后才生成预览；Workspace 导出仅限已接收确认的交接单，且必须绑定预览校验值（`previewSha256`）。Drive 写报告、Sheets 以幂等键登记、Gmail 只创建草稿；任一步失败可从持久步骤状态恢复，不重复已完成写入。

全部状态变更带 `expectedVersion`（冲突返回 409）并写入追加式事件时间线；交接单列表支持"待我审核 / 待我接收 / 逾期 / 已完成"筛选。

## 8. 常见问题

- 页面短暂显示 API 不可用：开发热重启期间前端会重试；确认 `/api/health` 最终为 `ok`。
- 导入失败：查看任务错误码；修正 Manifest 后使用原 `bundle_id` 显式重试。
- 本地 Git 返回 `403`：仓库不在 `LABLINEAGE_LOCAL_GIT_ROOTS` 允许目录。
- Agent 不可用：检查能力页和模型配置；不要把 API key 写入仓库。
- 报告校验失败：停止分发，检查对象存储完整性与审计日志。
